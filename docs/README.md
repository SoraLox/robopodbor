# РОБОПОДБОР — сопроводительная документация

Веб-платформа экспресс-предынвестиционной оценки роботизации: каталог решений, подбор под объект, расчёт экономики, сравнение сценариев, имитация работы роботов и выгрузка отчёта.

## Быстрый старт

```bash
docker compose up --build
```

Откройте <http://localhost:8080>. Демонстрационные учётные записи:

| Роль | Логин | Пароль |
|---|---|---|
| Пользователь | krylov@volga-logistic.ru | volga123 |
| Администратор | admin@robotopodbor.ru | admin123 |

Гостю вход не нужен: каталог и расчёт доступны сразу. Сайт на GitHub Pages работает без сервера, на встроенных моках, с теми же учётными записями.
